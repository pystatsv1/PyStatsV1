# SWL-S01, SWL-S06, and SWL-S07 source candidate

This private, synthetic-only PyStatsV1 batch supplies the study-specific assets
needed before Chapters 10 through 13 of *Psychological Statistics by Design*
may be drafted.

It includes:

- **SWL-S01:** a cross-sectional survey supporting a bounded correlation
  question and a separate within-domain multiple-regression prediction model;
- **SWL-S06:** a three-occasion confidence trajectory with six scheduled
  missing outcomes and an explicitly complete-case repeated-measures ANOVA;
- **SWL-S07:** a baseline-adjusted two-group comparison with a registered
  homogeneity-of-slopes diagnostic.

The batch is not a public companion release, does not change the PyPI package
version, does not authorize real data, and does not modify the private book
repository.

```bash
make psych-design-swl-s01-s06-s07-verify
make psych-design-swl-s01-s06-s07-r-verify
make psych-design-swl-s01-s06-s07-figures
```
